# 📖 oSamu - 现代 EPUB 阅读器

[English](README.md)

---

欢迎来到 **oSamu** 项目！这是一款基于 Readium 的跨平台 EPUB 阅读器，为书籍爱好者提供优雅的阅读体验。

## 🌐 访问网站
👉 **[访问 Github Pages](https://LoKaisham.github.io/oSamu-Release/)**
网站上提供了详细的应用介绍、功能特性、截图展示和下载链接。

## 🚀 快速开始

### 下载应用
| 平台 | 下载 |
|------|------|
| **Android** | [点击下载 APK](../../releases) |
> 打开上方 "Releases" 标签页，找到最新版本，下载 `.apk` 文件。

### 安装步骤
1. 下载 `oSamu-v*.apk` 文件。
2. 在 Android 设备上打开文件，按提示安装。
3. 打开应用，享受阅读！

## ✨ 功能特性
- 📖 **EPUB 阅读** - 基于 **Readium 3.2.0**，完整支持 EPUB2 和 EPUB3 标准。
- 🎨 **简约现代** - 采用 Material Design 3 设计语言。
- 🌈 **多色主题** - 丰富的主题选择满足个性化需求。
- 🌍 **多语言支持** - 现已支持简体中文、英语、日语、西班牙语、德语、法语。
- ⚡ **贴心设计** - 支持模糊搜索、快速回退等。

## 📚 如何使用

### 添加书籍
1. 在设备上准备 `.epub` 格式的电子书文件。
2. 打开 oSamu 应用。
3. 点击 "+" 按钮添加书籍文件。
4. 选择你的 EPUB 文件即可开始阅读。

### 阅读体验
- **翻页** - 点击屏幕左/右侧翻页。
- **调整字体** - 使用字体大小按钮。
- **更改主题** - 在设置中选择喜欢的主题颜色。
- **书签** - 长按可添加书签。
