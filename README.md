# 📖 oSamu - 现代EPUB阅读器

欢迎来到 **oSamu** 项目！这是一款基于Readium的跨平台EPUB阅读器，为书籍爱好者提供优雅的阅读体验。

## 🌐 访问网站

👉 **[oSamu应用官网](https://LoKaisham.github.io/oSamu-Release/)**

网站上提供了详细的应用介绍、功能特性、截图展示和下载链接。

## 🚀 快速开始

### 下载应用

| 平台 | 下载 |
|------|------|
| **Android** | [点击下载 APK](../../releases) |

> 打开上方"Releases"标签页，找到最新版本，下载 `.apk` 文件

### 安装步骤

1. 下载 `oSamu-v*.apk` 文件
2. 在Android设备上打开文件，按提示安装
3. 打开应用，享受阅读！

## ✨ 功能特性

- 📖 **EPUB阅读** - 完整支持EPUB2和EPUB3标准
- 🎨 **MD3风格UI** - 采用Material Design 3设计语言
- 🌈 **多色主题** - 丰富的主题选择满足个性化需求
- 🌍 **多语言支持** - 全球用户友好的界面
- ⚡ **高性能** - 快速加载和流畅的翻页体验

## 📱 系统要求

- **Android 8.0** 或更高版本
- **50MB** 以上存储空间

## 📚 如何使用

### 添加书籍
1. 在设备上准备 `.epub` 格式的电子书文件
2. 打开oSamu应用
3. 点击"+"按钮添加书籍文件
4. 选择你的EPUB文件即可开始阅读

### 阅读体验
- **翻页** - 点击屏幕左/右侧翻页
- **调整字体** - 使用字体大小按钮
- **更改主题** - 在设置中选择喜欢的主题颜色
- **书签** - 长按可添加书签

## 常见问题

### Q: oSamu是免费的吗？
**A:** 是的！oSamu完全免费使用。

### Q: 支持哪些EPUB版本？
**A:** 支持EPUB2和EPUB3标准。

### Q: 是否支持其他电子书格式？
**A:** 目前主要支持EPUB格式。

### Q: 我的数据会被保存吗？
**A:** 所有数据本地保存在你的设备上，不会上传到云端。
