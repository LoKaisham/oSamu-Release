# 📖 oSamu - Modern EPUB Reader

[中文版](README.zh.md)

---

Welcome to **oSamu**! This is a cross-platform EPUB reader based on Readium, providing an elegant reading experience for book lovers.

## 🌐 Visit Website
👉 **[Visit Github Pages](https://LoKaisham.github.io/oSamu-Release/)**
The website provides detailed introduction, features, screenshots, and download links.

## 🚀 Quick Start

### Download App
| Platform | Download |
|------|------|
| **Android** | [Download APK](../../releases) |
> Go to the "Releases" tab, find the latest version, and download the `.apk` file.

### Installation
1. Download `oSamu-v*.apk` file.
2. Open the file on your Android device and follow the prompts.
3. Open the app and enjoy reading!

## ✨ Features
- 📖 **EPUB Reading** - Based on **Readium 3.2.0**, full support for EPUB2 and EPUB3 standards.
- 🎨 **Minimalist & Modern** - Adopts Material Design 3 design language.
- 🌈 **Multi-color Themes** - Rich theme choices to suit your style.
- 🌍 **Multilingual** - Supports Simplified Chinese, English, Japanese, Spanish, German, and French.
- ⚡ **Thoughtful Design** - Supports fuzzy search, fast rollback, and more.

## 📚 How to Use

### Add Books
1. Prepare `.epub` format e-book files on your device.
2. Open the oSamu app.
3. Click the "+" button to add book files.
4. Select your EPUB file to start reading.

### Reading Experience
- **Page Turning** - Tap the left/right side of the screen.
- **Adjust Font** - Use the font size buttons.
- **Change Theme** - Select your favorite theme color in settings.
- **Bookmarks** - Long press to add a bookmark.

### Q: Is oSamu free?
